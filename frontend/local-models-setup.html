Local Models Setup Guide

Connect your locally-hosted AI models to Restruct. Run models on your own hardware for full control over latency, privacy, and cost. This guide will walk you through setting up local model inference with Ollama.

Getting Started with Ollama

Ollama is the recommended local inference server for Restruct. It's easy to install, supports a wide range of models, and provides a simple API for model interaction.

Install Ollama

Download and install Ollama for your operating system:

  • macOS/Linux: Run curl -fsSL https://ollama.ai/install.sh | sh
  • Windows: Download the installer from ollama.ai

After installation, verify Ollama is running with:

ollama --version

Pull Your First Model

Download a model to your local machine. We recommend starting with Llama 3.1 8B for a good balance of performance and resource usage:

ollama pull llama3.1

Other popular starter models:

ollama pull mistral ollama pull phi3 ollama pull gemma2

Start the Ollama Server

Ollama typically starts automatically, but you can manually start it with:

ollama serve

By default, Ollama runs on http://localhost:11434. Verify it's running by visiting this URL in your browser or running:

curl http://localhost:11434

Test Your Model

Try running a simple inference to ensure everything works:

ollama run llama3.1 "Hello, how are you?"

If you see a response, your local model is working correctly!

Enable in Restruct

Return to the Restruct routing lab and toggle the "Local Models" node to ON. Your local models will now be available for routing!

Performance Tips

  • Start with smaller models (1B-8B parameters) if you have limited RAM
  • Larger models (70B+) require significant GPU memory (24GB+ VRAM recommended)
  • Use quantized versions (Q4, Q5) for faster inference with minimal quality loss
  • Keep Ollama updated: ollama update

Advanced Configuration

Custom Model Parameters

You can customize model behavior with Ollama's Modelfile system. Create a Modelfile to set temperature, context length, and system prompts:

FROM llama3.1 PARAMETER temperature 0.8 PARAMETER num_ctx 8192 SYSTEM You are a helpful AI assistant.

Then create a custom model:

ollama create my-custom-model -f Modelfile

GPU Acceleration

Ollama automatically uses GPU acceleration when available. Supported GPUs:

  • NVIDIA GPUs with CUDA support
  • Apple Silicon (M1, M2, M3, M4) with Metal
  • AMD GPUs with ROCm (Linux only)

Connecting Multiple Ollama Instances

If you have multiple machines running Ollama, you can configure Restruct to route to different servers by setting custom endpoints in your routing profile.

Troubleshooting

  • Model not responding: Ensure Ollama is running with ollama serve
  • Out of memory: Try a smaller model or use quantized versions
  • Slow performance: Check if GPU acceleration is working with nvidia-smi (NVIDIA) or Activity Monitor (Mac)
  • Connection refused: Verify Ollama is listening on port 11434
